# Şəhla Müseyibova — İngilis Dili Müəllimi GitHub Səhifəsi

Bu repozitoriya **Şəhla Müseyibova**nın tədris portalıdır.

## 🌐 Canlı Səhifə

GitHub Pages aktiv olduqdan sonra bu linkdən daxil olun:
`https://[sizin-github-adınız].github.io/shehla-museyibova/`

## 📂 Qovluq Strukturu

```
shehla-museyibova/
├── index.html              ← Əsas səhifə
├── css/
│   └── style.css           ← Dizayn
├── js/
│   └── main.js             ← Funksionallıq
├── materials/

```

## 🚀 GitHub Pages Qurulması

1. GitHub-a daxil olun → **New repository** → adı: `shehla-museyibova`
2. Bütün faylları yükləyin
3. **Settings → Pages → Source: main branch / root**
4. Saytınız hazırdır!

## 📸 Foto Əlavə Etmək

Öz fotoğrafınızı `photo.jpg` adı ilə bu qovluğa əlavə edin,
sonra `index.html`-də aşağıdakı sətri açın (komment xəttini silin):

```html
<div class="hero-photo"><img src="photo.jpg" alt="Şəhla Müseyibova" /></div>
```

və üstündəki `<div class="photo-placeholder">` blokunu silin.
